# 用户操作指南

## 概述

本指南详细介绍了电动滑板车租赁系统的用户操作流程，包括客户和管理员的功能使用说明。

## 客户功能指南

### 1. 注册与登录

#### 注册新账号
1. 访问系统首页，点击"立即注册"
2. 填写用户名、邮箱、密码
3. 选择身份（学生/老年人可享受折扣）
4. 点击"注册"完成账号创建

#### 登录系统
1. 输入用户名和密码
2. 点击"登录"按钮
3. 成功登录后自动跳转到滑板车列表页面

### 2. 浏览滑板车

#### 查看可用滑板车
1. 登录后进入"滑板车列表"页面
2. 系统显示所有滑板车信息
3. 绿色标签表示可用，红色标签表示不可用

#### 滑板车信息说明
- **型号**: 滑板车的具体型号
- **小时价**: 每小时租赁价格
- **日价**: 每日租赁价格
- **状态**: 当前可用状态

### 3. 预订滑板车

#### 预订流程
1. 点击"预订滑板车"按钮或具体滑板车的"预订"按钮
2. 选择租赁时长（1小时/4小时/1天/1周）
3. 输入模拟信用卡号（任意12位以上数字）
4. 系统自动计算价格并显示折扣信息
5. 确认预订完成支付

#### 折扣说明
- **频繁用户**: 7天内租赁满8小时享9折
- **学生/老年人**: 享9.5折优惠
- **取最大折扣**: 不叠加，取最优折扣

### 4. 管理预订

#### 查看预订记录
1. 点击左侧菜单"我的预订"
2. 查看"进行中"和"历史记录"标签页

#### 取消预订
1. 在"进行中"标签页找到待开始的预订
2. 点击"取消"按钮
3. 确认取消操作

#### 延长预订
1. 在"进行中"标签页找到进行中的预订
2. 点击"延长"按钮
3. 选择延长时间段
4. 确认延长操作

### 5. 提交反馈

#### 提交反馈
1. 点击左侧菜单"意见反馈"
2. 填写反馈标题和详细描述
3. 点击"提交反馈"按钮

#### 查看反馈记录
1. 在反馈页面下方查看历史反馈
2. 查看反馈处理状态和优先级

## 管理员功能指南

### 1. 管理仪表盘

#### 查看统计数据
1. 登录管理员账号
2. 进入"管理仪表盘"
3. 查看总滑板车数量、可用滑板车、本周收入

#### 收入分析
- **每周收入统计**: 饼图显示不同时长租赁的收入分布
- **每日收入统计**: 柱状图显示7天内的每日收入

### 2. 滑板车管理

#### 新增滑板车
1. 进入"滑板车管理"页面
2. 点击"新增滑板车"按钮
3. 填写型号、小时价、日价
4. 确认新增

#### 编辑滑板车
1. 在滑板车列表中找到目标滑板车
2. 点击"编辑"按钮
3. 修改相关信息
4. 确认保存

### 3. 代用户下单

#### 代下单流程
1. 在仪表盘点击"代用户下单"
2. 输入用户邮箱
3. 选择滑板车和租赁时长
4. 确认下单

### 4. 反馈管理

#### 管理用户反馈
1. 进入"反馈管理"页面
2. 查看所有用户提交的反馈
3. 使用筛选功能按优先级或状态查看

#### 设置优先级
1. 找到需要处理的反馈
2. 点击"设为高优先级"或"设为低优先级"
3. 系统自动更新优先级状态

## 常见问题

### Q: 如何享受折扣？
A: 注册时选择学生或老年人身份，或成为频繁用户（7天内租赁满8小时）

### Q: 预订后可以取消吗？
A: 可以，但只能取消未开始的预订

### Q: 如何延长正在进行中的预订？
A: 在"我的预订"页面找到进行中的预订，点击"延长"按钮

### Q: 支付需要真实信用卡吗？
A: 不需要，系统为模拟支付，任意12位以上数字即可

### Q: 管理员账号是什么？
A: 用户名: admin, 密码: admin

## 注意事项

1. 预订成功后滑板车状态变为"不可用"
2. 取消或到期后滑板车自动恢复"可用"状态
3. 延长预订仅增加时长，不重新计算折扣
4. 反馈提交后管理员会及时处理
5. 系统支持响应式布局，可在手机和电脑上使用
